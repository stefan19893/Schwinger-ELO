# Phase 2 — Bout parser (Milestone 2)
**Agent:** data-engineer

## Goal
Extract every bout (Gang) with outcome and grades, plus raw athlete metadata.

## Exit criteria
- `src/scraper/bouts_parser.py` produces DataFrames matching the `Bout` and `Athlete` schemas.
- Outcome (`WIN_A`/`WIN_B`/`DRAW`) and grades (8.25–10.00) validated; invalid rows logged, not silently dropped.
- Handles 6-Gang festivals and 8-Gang ESAF.
- `python -m src.cli parse` wired up.
- Offline sample dataset in `tests/fixtures/sample/` (a few festivals, incl. one ESAF) usable via `--sample`.
- Fixture-based tests incl. an ESAF sheet and a draw-heavy sheet.

## Known risks from Phase 1 review
Logged 2026-09-29 from the Phase 1 phase-reviewer; details in `phase-1-crawler.md` (task 1 + task 7 notes). Not yet addressed.
- **Shared statistic PDF URL:** Schwarzenberg-Schwinget 2022 and Frühjahrsschwinget Oberarth 2022 both point to `.../Statistik-1.pdf.pdf`. Verify each PDF's header (festival name/date) against the `festivals` row before attaching bouts; flag mismatches instead of importing.
- **Youth-mixed PDFs 2012–2015:** 13 Regional festivals have statistic PDFs described "(inkl. Nachwuchs)" — keep only the active (Aktive) category.
- **Borderline events** — decide (and log under Decisions) whether they count toward ELO: Mannschaftsmeisterschaft Comptoir Lausanne 2015 (team format), Rangschwinget Jungaktive Sarnen 2021 (young actives), Ausland events (e.g. Quebec/Kanada), Hallenschwinget (indoor, often reduced fields).
- **Request budget:** ~1880 statistic-PDF downloads exceed the 1500 `crawl_max_requests` cap — PDFs need their own cap setting and cache policy (PDFs of finished festivals never change → cache forever; consider a separate `max_age` rule only for current-season festivals).
- **`pypdf` not in `requirements.txt`** yet (tested in Phase 1, gives clean text).
- **Parsing quirks:** the Schlussgang loser is printed as `o` with a loss grade (e.g. ESAF 2019 Wicki Gang 8 `o Stucki 8.75` vs Stucki `+ Wicki 10.00`) — derive outcomes from both sides/grades; duplicate names carry suffixes ("Herger Elias 1" / "Herger Elias 2") — keep them for identity resolution in Phase 3.

- 2026-09-29 — **Task 2 done.** `src/scraper/bouts_parser.py`: `parse_festival(text, fest_id, date, name, max_gang)` → `FestivalParse(layout, status ok|partial|failed|header_mismatch, athletes, bouts, rejects, header_check, youth_blocks, entries_total)`; `to_frames()` → (bouts, athletes_raw, rejects) DataFrames. Pipeline: `normalize_text` (NFKC, soft hyphens) → `detect_layout` → layout parser → `verify_header` → `build_festival` (pairing).
  - **Layouts:** `standard` (incl. rank variants `1.`/`2.a`/`26aa`/bare `b`, glued marks `3a*`, points glued to stars/names, `57.25 a*`, rank-less headers, headers broken over 2–5 lines, reversed `o 8.75 Name` lines), `notenblatt` (AG/BL "Notenblätterdetails": points(k), entries(k), `rank name(k) points(k+1)`), `blocks` (symbol column padded to 6 → bouts = number of opponent lines), `rang` (NOSV `Rang: N`, numbered entries, `u` = injury), `multicol` (cells by order per row; Heller "(SWS) E" and Bernese "Presseliste" with Gau codes / glued numbers / Excel row numbers / wrapped cells). `empty`/`garbled` → festival reject.
  - **Pairing:** each bout appears twice; opponent resolved by full name key, else base key (without parentheses) if unique; same-name athletes are told apart by which one lists the current athlete (mirror) — resolves e.g. two "Gisler Silvan" (S/T) at Sarnen 2021. k-th A-vs-B entry pairs with k-th B-vs-A entry (rematches). Outcome from both symbols; if they disagree but grades are unambiguous (≥ 9.25 vs ≤ 8.75) the grades decide (`symbol_conflict_resolved_by_grades`), else reject.
  - **Gang numbers:** list positions are lower bounds (athletes who miss a Gang have shorter lists); position from a complete list wins (`gang_inferred`), both complete but different → `gang_uncertain` (sheets are not always in strict Gang order; strict-order propagation was tried and made things worse). Gang only orders bouts within a festival.
  - **Rejects (never silent):** stages festival/athlete/entry/bout/line; invariant `entries = 2·bouts + entry rejects + 2·bout rejects` holds for all 1879 sheets and is tested. Injury/forfeit bouts (`u`, `> unfall`, 0.00 grade) → `forfeit_injury`; `z` extra bouts (no grade) → `extra_bout_without_grade`; youth-section opponents → `opponent_in_youth_section`.
  - **Youth-mixed sheets:** only "Aktive"/"Actif" (or unsectioned) blocks kept; a bare year line is a youth birth-year category unless it is (≈) the festival year — this alone fixed 132 festivals whose wrapped titles ("…Interlaken" / "2023") had been read as youth sections.
  - **Header check:** dates (numeric, two-day `30.-31.08.2025`, German/French month names) within ±1 day, else festival-name token; only a definite date mismatch blocks import (shared Oberarth/Schwarzenberg sheet → Schwarzenberg `header_mismatch`).
